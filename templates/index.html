🧭 Using this page

  • Poincaré Sphere: live 3D state (white dot) and recent trace, drag to rotate, scroll to zoom. The outer circle is the sphere's true outline; the bright cyan circle is the equator (S1–S2 plane - every purely linear-polarization state lives on it); the two fainter circles are the other two reference meridians, and the three straight lines through the centre connect the six cardinal states: H/V (horizontal/vertical), D/A (diagonal +45°/anti-diagonal -45°) and R/L (right/left circular). Depending on which way you've rotated the view, a meridian can appear as a thin ellipse "inside" the outline - that's normal perspective foreshortening, not a second sphere.
  • Polarization Ellipse: the instantaneous polarization ellipse from azimuth θ and ellipticity η (bright white), with handedness and axial ratio.
  • Persistence trace: both the sphere and the ellipse show recent history as a colour gradient, the same idea as the persistence display on a LeCroy scope - dim/dark indigo is old, bright yellow/white-hot is the most recent, and the current reading is drawn in white on top so it's always unambiguous.
  • Normalize checkbox (in the strip below the tabs, checked by default): scales the sphere trace and the ellipse by the actual degree of polarization, so a partially-polarized state correctly sits closer to the centre of the sphere / draws a smaller ellipse rather than always looking fully polarized. Uncheck it to see the idealised orientation only, ignoring DOP.
  • Stokes History: S0–S3 (normalised) and power plotted vs. sample — useful for aligning a beam by eye while watching the trend.
  • Settings: auto-detected device list (no need to type a VISA address - just pick the serial number), wavelength, measurement mode, waveplate motor on/off & speed, power range, and a CSV export of everything currently buffered.
  • Power, DOP and S0–S3, plus the trace/history length control (including switching it off), are always shown in the strip below the tabs, regardless of which tab is open. Hover the small "i" next to any label for what it means.

📡 SCPI Interface

The SCPI server is accessible via TCP/IP on port 5025. Standard PAX1000 SCPI commands are forwarded straight to the instrument, so anything from the Thorlabs programmer's reference works unmodified, plus a few local convenience commands listed below.

Connection Details:
IP Address: {{ ipa }}
Port: 5025
Protocol: TCP/IP 
# Connect via telnet
telnet {{ ipa }} 5025

# Try it:
*IDN?
SENS:DATA:LAT?
POL:STOKES?
POL:STOKES:RAW?

Standard PAX1000 commands (passthrough)

  • *IDN? - Get device identification
  • SENS:DATA:LAT? - Latest scan: revs, timestamp, mode, flags, TIA range, ADC min/max, revolution time, misadjustment, theta (rad), eta (rad), DOP, power (W)
  • SENS:CORR:WAV <m> / SENS:CORR:WAV? - Set/query wavelength in metres
  • INP:ROT:STAT 0|1 / INP:ROT:STAT? - Waveplate motor on/off
  • INP:ROT:VEL <hz> / INP:ROT:VEL? - Set/query rotation speed
  • INP:ROT:SETT? - Is the motor speed settled?
  • SENS:CALC <mode> / SENS:CALC? - Measurement mode (0=IDLE ... 9=D2048)
  • SENS:POW:RANG:AUTO 0|1|2 - Power auto-range off/on/once
  • SENS:POW:RANG:IND <1-16> - Manual power range index
  • CAL:STR? - Calibration date string

Local extensions (not part of the PAX1000 itself)

  • POL:STOKES? - Latest normalised Stokes parameters S0,S1,S2,S3 (S0=1)
  • POL:STOKES:RAW? - Latest raw Stokes parameters S0,S1,S2,S3 in watts (S0 = optical power)
  • POL:DOP? - Latest degree of polarization (0..1)
  • POL:TEMP:STATUS? - OK / ABOVE_LIMIT / BELOW_LIMIT. This is a warning flag from the instrument, not a numeric temperature - the PAX1000's SCPI set doesn't expose one.
  • POL:CONFIG? - Current device settings as one line (wavelength, mode, motor state/speed, power range, VISA resource), so a measurement can be reproduced later
  • POL:HIST? <n> - Last n history rows as CSV (timestamp,theta,eta,dop,power,s0,s1,s2,s3,rs0,rs1,rs2,rs3)
  • POL:HIST:LEN? - Number of samples currently buffered
  • SYST:HELP? - This command summary

🐍 Minimal control script

No special packages needed — this talks to the SCPI server above over a plain socket:

#!/usr/bin/env python3
import socket

class PAX1000SCPI:
    """Minimal SCPI client for the PAX1000 polarimeter web/SCPI server"""

    def __init__(self, host='{{ ipa }}', port=5025, timeout=2.0):
        self.sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.sock.settimeout(timeout)
        self.sock.connect((host, port))
        self.sock.recv(1024)  # discard the "Ready" banner

    def query(self, command):
        self.sock.sendall((command + '\n').encode())
        return self.sock.recv(4096).decode().strip()

    def write(self, command):
        self.sock.sendall((command + '\n').encode())

    def close(self):
        self.sock.close()

    # convenience wrappers
    def stokes(self):
        """Normalised Stokes parameters S0..S3 (S0=1)"""
        return [float(v) for v in self.query('POL:STOKES?').split(',')]

    def stokes_raw(self):
        """Raw Stokes parameters S0..S3 in watts"""
        return [float(v) for v in self.query('POL:STOKES:RAW?').split(',')]

    def dop(self):
        """Degree of polarization, 0..1"""
        return float(self.query('POL:DOP?'))

    def temp_status(self):
        """'OK' / 'ABOVE_LIMIT' / 'BELOW_LIMIT' (warning flag, not a reading)"""
        return self.query('POL:TEMP:STATUS?')

    def config(self):
        """Current device settings as a dict, e.g. to log alongside a
        measurement so it can be reproduced later"""
        raw = self.query('POL:CONFIG?')
        return dict(kv.split('=', 1) for kv in raw.split(','))


if __name__ == '__main__':
    pax = PAX1000SCPI()
    print("IDN:", pax.query('*IDN?'))
    print("Stokes (normalised):", pax.stokes())
    print("Stokes (raw, W):", pax.stokes_raw())
    print("DOP:", pax.dop())
    print("Temperature status:", pax.temp_status())
    print("Config:", pax.config())
    pax.close()
