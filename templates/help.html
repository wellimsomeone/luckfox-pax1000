📡 SCPI Interface

The PAX1000 polarimeter can be controlled programmatically via a SCPI (Standard Commands for Programmable Instruments) interface. Standard PAX1000 SCPI commands are forwarded straight through to the instrument, so anything from the Thorlabs programmer's reference works unmodified.

Connection Information

The SCPI server is accessible via TCP/IP on port 5025. You can connect using telnet, socket programming, or any SCPI-compatible library.

Testing the Connection

You can test the SCPI interface using telnet from your terminal:

# Connect via telnet
telnet {{ ipa }} 5025

# Once connected, try these commands:
*IDN?                    # Get device identification
SENS:DATA:LAT?           # Get the latest scan (theta, eta, DOP, power, ...)
SENS:CORR:WAV?           # Query wavelength setting (m)
INP:ROT:VEL?              # Query waveplate rotation speed (1/s)
POL:STOKES?                # Latest normalised Stokes parameters S0,S1,S2,S3
POL:STOKES:RAW?             # Latest raw Stokes parameters S0,S1,S2,S3 (watts)
POL:DOP?                     # Latest degree of polarization
POL:CONFIG?                   # Current settings, to reproduce a measurement

Python Control Example

A minimal Python example using plain socket programming: 

#!/usr/bin/env python3
import socket

class PAX1000SCPI:
    """Simple SCPI interface for the PAX1000 polarimeter"""

    def __init__(self, host='{{ ipa }}', port=5025, timeout=2.0):
        self.sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.sock.settimeout(timeout)
        self.sock.connect((host, port))
        self.sock.recv(1024)  # discard the "Ready" banner

    def query(self, command):
        self.sock.sendall((command + '\n').encode())
        return self.sock.recv(4096).decode().strip()

    def write(self, command):
        self.sock.sendall((command + '\n').encode())

    def close(self):
        self.sock.close()

    def stokes(self):
        """Normalised Stokes parameters S0..S3 (S0=1)"""
        return [float(v) for v in self.query('POL:STOKES?').split(',')]

    def stokes_raw(self):
        """Raw Stokes parameters S0..S3 in watts"""
        return [float(v) for v in self.query('POL:STOKES:RAW?').split(',')]

    def dop(self):
        """Degree of polarization, 0..1"""
        return float(self.query('POL:DOP?'))

    def config(self):
        """Current device settings as a dict, to reproduce a measurement"""
        raw = self.query('POL:CONFIG?')
        return dict(kv.split('=', 1) for kv in raw.split(','))


if __name__ == '__main__':
    pax = PAX1000SCPI()
    print("IDN:", pax.query('*IDN?'))
    print("Latest scan:", pax.query('SENS:DATA:LAT?'))
    print("Stokes (normalised):", pax.stokes())
    print("Stokes (raw, W):", pax.stokes_raw())
    print("DOP:", pax.dop())
    print("Config:", pax.config())
    pax.close()

Common SCPI Commands

  • *IDN? - Get device identification
  • SENS:DATA:LAT? - Latest scan: revs, timestamp, mode, flags, TIA range, ADC min/max, revolution time, misadjustment, theta (rad), eta (rad), DOP, power (W)
  • SENS:CORR:WAV <m> / SENS:CORR:WAV? - Set/query wavelength in metres
  • INP:ROT:STAT 0|1 / INP:ROT:STAT? - Waveplate motor on/off
  • INP:ROT:VEL <hz> / INP:ROT:VEL? - Set/query rotation speed
  • INP:ROT:SETT? - Is the motor speed settled?
  • SENS:CALC <mode> / SENS:CALC? - Measurement mode (0=IDLE ... 9=D2048)
  • SENS:POW:RANG:AUTO 0|1|2 - Power auto-range off/on/once
  • SENS:POW:RANG:IND <1-16> - Manual power range index
  • CAL:STR? - Calibration date string

Local Extensions

A few convenience commands are added by this server (not part of the PAX1000 itself):

  • POL:STOKES? - Latest normalised Stokes parameters as S0,S1,S2,S3
  • POL:STOKES:RAW? - Latest raw Stokes parameters as S0,S1,S2,S3 in watts (S0 = optical power)
  • POL:DOP? - Latest degree of polarization (0..1)
  • POL:TEMP:STATUS? - OK/ABOVE_LIMIT/BELOW_LIMIT warning flag (the PAX1000 has no numeric temperature reading over SCPI)
  • POL:CONFIG? - Current settings as one line (wavelength, mode, motor, power range), to reproduce a measurement
  • POL:HIST? <n> - Last n history rows as CSV (timestamp,theta,eta,dop,power,s0,s1,s2,s3,rs0,rs1,rs2,rs3)
  • POL:HIST:LEN? - Number of samples currently buffered
  • SYST:HELP? - This command summary

Tips for Programming

  • Check INP:ROT:SETT? before relying on a fresh measurement after changing the motor speed
  • Add small delays after setting values to allow the waveplate / hardware to settle
  • Use try/except blocks to handle network errors gracefully
  • Close the connection properly when done to free resources
  • For continuous monitoring, the web interface already polls at a fast rate — use the History tab to align a beam by eye
